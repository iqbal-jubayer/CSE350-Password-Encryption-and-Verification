<h1>Password Encryption & Verification</h1>

> A password security project developed for CSE350 to demonstrate secure password handling,
password protection, and verification.

<h2>Project Overview</h2>

This project implements a password protection system that allows a user to securely store and verify passwords without 
directly exposing the original password.

The project demonstrates how password security mechanisms can be implemented programmatically and highlights 
the importance of protecting user credentials.

<h2>Features</h2>

- Password input
- Password protection/encryption
- Secure credential storage
- Password verification
- Detection of incorrect passwords
- Simple and user-friendly implementation
